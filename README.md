# Story A/B

**先别激动**\
**另一个人还没开口。**

Story A/B\
一份原稿，两个真相。\

`story-ab` 是一个叙事改写 Skill。它保留原文的事实骨架、篇章格式、语言节奏和认知毛边，将故事交给原文中被描述、被安排或被沉默的另一方重新讲述。

它不是简单交换人称，也不是把原文改写成正反观点摘要。它更关心：同一批事件、数字、对白和物件，换一个人掌握解释权以后，会呈现出什么不同的意义。

## 适用场景

- 换到故事另一方的第一人称；
- 写出“同一件事，两种真相”的 A/B 版本；
- 生成镜像叙事或对立视角版本；
- 保留原文格式与气质，让原有细节反过来改变叙事含义。

不适用于普通润色、事实核验、观点总结或机械替换人称。

## 核心原则

- **事实不动**：保留原文给出的事件顺序、数字、地点、物件和关键台词。
- **格式同构**：尽量保留标题句法、篇幅、分节、分隔符、对白密度和首尾外形。
- **认知毛边同构**：保留人物的糊涂、虚荣、矛盾、跑题、粗糙表达和无用细节。
- **选择性翻面**：只改变少量真正控制叙事权的锚点，不让每个物件都服务同一个主题。
- **反平滑**：减少密集金句、完整心理解释、整齐排比和过度完美的结尾。

## 文件结构

```text
story-ab/
├── LICENSE
├── SKILL.md
└── agents/
    └── openai.yaml
```

- `LICENSE`：MIT License，允许使用、复制、修改和分发。
- `SKILL.md`：Skill 的完整方法和执行规则。
- `agents/openai.yaml`：显示名称、简短介绍和默认调用提示词，不包含密钥或账号信息。

## 安装

安装到 Codex 的用户级 Skills 目录：

```bash
git clone https://github.com/wildbyteai/story-ab.git ~/.codex/skills/story-ab
```

也可以安装到项目目录：

```bash
mkdir -p .agents/skills
git clone https://github.com/wildbyteai/story-ab.git .agents/skills/story-ab
```

如果你的 Agent 使用其他 Skills 目录，将整个仓库放入对应目录即可。核心入口始终是 `SKILL.md`。

## 使用

```text
使用 $story-ab，保留原文事实、篇幅、分节、语言节奏与未解释的毛边，将下面文字改写为对立视角叙事。
```

可以额外指定：

- B 版叙事者；
- 恶趣味强度，默认 `6/10`；
- 是否保留真实姓名；
- 目标平台或长度。

未指定叙事者时，Skill 默认选择原文中“被写得最多、却最少拥有内心”的角色。

## 示例请求

```text
使用 $story-ab，把这篇男方第一人称故事改写成女方第一人称。
保留原来的标题句式、六段结构、分隔线和关键物件。
恶趣味强度 6/10，不要把女方写成完美受害者。
```

## 边界

`story-ab` 是叙事实验，不是事实裁定工具。处理真实人物时，不应新增原文没有的可验证事件、引语、诊断、金额、关系或违法指控。

方法归属：BYTEWATCHER 内容系统 BW-0016。
